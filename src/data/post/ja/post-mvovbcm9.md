## 1. 突如訪れたCSチャットボットの危機とビジュアル対応の裏側

丸の内のITオフィスで迎えた金曜日の午後、私たちのチームが開発した顧客対応（CS）自動チャットボットが、悪意ある脱獄（Jailbreak）プロンプトの攻撃を受け、システムが一時的に不安定になるという緊急事態が発生しました。ユーザーからの質問を装った不正な入力を防ぐため、セキュリティの再構築と同時に、UI上の緊急メンテナンス告知や、ユーザーを安心させるための視覚的なカスタムSVGアイコンを即座に刷新する必要に迫られたのです。

「今すぐ、ブランドカラーに準拠したセキュアでモダンな警告用SVGアイコンとWebイラストを3パターン作ってほしい」とデザイン部門のリーダーから声がかかりました。従来の画像生成AIでは、線のシャープさやコードの微調整が難しく、Webサイトへの組み込みに何時間もロスしてしまいます。そこで私が武器として取り出したのが、**ClaudeのArtifacts機能**を活用したSVG直接生成プロンプトでした。

## 2. なぜ通常のプロンプトでは失敗するのか？構造的アプローチ

多くの人が「綺麗なアイコンを作って」という抽象的なプロンプトを入力しがちですが、これではLLMが持つデフォルトの美的感覚に依存してしまい、実務で使えるクオリティになりません。特にWebイラストやSVGアイコンの生成において重要なのは、以下の3つの要素をプロンプトにあらかじめ定義しておくことです。

1.**viewBoxとスケーラビリティの明記**: レスポンシブ対応に必要なコード構造を指定する。
2.**パレットの制限**: ブランドカラー（例: #84cc16のアシッドライムなど）を指定し、無駄なカラーバリエーションを防ぐ。
3.**セマンティックな構造**: パス（path）のグループ化や、CSSクラスの付与ルールを指示して後からの改変を容易にする。

これらを欠いた状態で生成を始めると、タグの閉じ忘れや不自然な重なりが発生し、エンジニアが手動でコードを書き直す羽目になります。アーキテクトとして、出力フォーマットを厳密に制限することがプロンプトエンジニアリングの核心です。

## 3. マスタープロンプトテンプレート

実際の業務で即座にコピー＆ペーストして使える、Claude Artifacts専用のマスタープロンプトです。プレースホルダーをご自身のプロジェクトに合わせて書き換えてご活用ください。

```markdown
# 役割
あなたは世界トップクラスのUI/UXデザイナー兼SVGエキスパートです。
以下の要件に従い、モダンで洗練されたカスタムSVGアイコン/WebイラストをClaudeのArtifacts機能用に出力してください。

## デザイン要件
- テーマ: [ここにテーマや利用シーンを記入。例: セキュリティ警告、システムメンテナンス]
- スタイル: [フラット、アイソメトリック、線画、ニューモーフィズムなど]
- カラーパレット: メインカラーは #84cc16、サブカラーは #111827、アクセントは #ffffff を使用
- 形状のトーン: 角丸を活かした親しみやすくも信頼感のあるデザイン

## 技術要件
- コードは完全にクリーンな有効なSVGタグ（<svg>...</svg>）のみを出力する
- viewBox="0 0 24 24" (または適切なアスペクト比)を設定する
- 各パスには適切なクラス名やidを付与し、CSSでのアニメーションや色変更に対応させる
- 外部ライブラリへの依存や不要なメタデータを含めないこと

それでは、Artifacts上でプレビュー可能なSVGを出力してください。
```

## 4. 実践的なバリエーションとセキュリティ・安全性のヒント

現場での運用をさらにスムーズにするための応用テクニックをいくつか共有します。

* **インライン編集の指示**: 「このSVGの右側に、小さな警告マークを追加して」といった追加指示を出す際は、新規にすべて生成させるのではなく、既存のArtifactsのコードを差分更新させるプロンプトを意識してください。
* **アクセシビリティ（a11y）の確保**: プロンプト内に `<title>` タグや `aria-label` の自動挿入を義務付けることで、生成された瞬間からアクセシビリティ対応済みの素材を手に入れることができます。
* **セキュリティ対策としてのサンドボックス**: 冒頭のCSチャットボットの件と同様に、外部からの不正な入力を受け付けるシステム周辺のデザインアセット作成では、AIツール自体のハルシネーションによる機密情報の混入を防ぐため、常に静的なデザインデータ生成に用途を限定することが肝心です。

## 5. よくある質問 (FAQ)

**Q.** ChatGPTの画像生成機能とClaudeのArtifactsによるSVG生成の最大の違いは何ですか？

**A.** ChatGPTのDALL-Eなどはラスター画像（PNG/JPG）を生成するため、後からの色変更や拡大時に画質が劣化します。一方、ClaudeのArtifactsはベクターコード（SVG）を直接記述・プレビューできるため、Webサイトにそのまま組み込め、CSSで自由自在にスタイリングやアニメーション化が可能です。

**Q.** 生成されたSVGコードが途中で途切れてしまう場合はどうすればよいですか？

**A.** プロンプトの末尾に「コードが長くなる場合は、分割して出力するか、省略せずに完結させてください」と指定するか、途切れた際に「続きのコードを出力してください」とだけ指示すれば、Artifacts機能が自動で結合を処理してくれます。

**Q.** 商用利用や著作権上の問題はありませんか？

**A.** Claudeなどの生成AIがコードとして出力したSVGの図形要素自体は、特定の既存著作物の直接的なコピーでない限り、商用WebサイトやアプリケーションのUIパーツとして安全にご利用いただけます。ただし、念のため実運用前には独自のデザインガイドラインに適合しているか確認することをお勧めします。
