## なぜ普通のプロンプトではYouTubeの構造分析に失敗するのか？

多くの人がやりがちな失敗は、以下のような曖昧な指示です。

* <strong>失敗例:</strong> 「このYouTubeの台本を読んで、面白いポイントをまとめて」
* <strong>結果:</strong> あらすじの要約になるだけで、視聴者がなぜその動画に惹きつけられたのかという「構成の骨組み（骨格）」が見えてこない。

バズる動画には、共通の「フック（0-15秒）」「問題提起」「共感の深化」「情報の出し惜しみ（オープンループ）」「最大のベネフィット」「CTA（行動喚起）」という緻密な драматурギ（劇作法）が存在します。

AIにこれを正確に抽出させるためには、<strong>「どのような視点で、どのフレームワークを使って分解するか」</strong>をシステムプロンプトや前提条件として明示的に指定する必要があります。つまり、AIを一流の「YouTubeコンテンツ・アナリスト」としてロールプレイさせるのです。

## 実戦投入型！YouTube台本リバースエンジニアリング・マスタープロンプト

以下のプロンプトを、ChatGPTやClaudeの入力欄にコピー＆ペーストしてください。`[対象のYouTube台本テキストや文字起こしデータをここに貼り付け]` の部分を、分析したい動画のデータに置き換えるだけです。

```markdown
# 役割
あなたは世界最高峰のYouTubeコンサルタント兼、動画構成作家です。視聴維持率（Retention Rate）とクリック率（CTR）の心理的要因を完全に理解しています。

# 目的
提供されたYouTube動画の台本（文字起こしデータ）を徹底的に逆算し、どのような構造・心理テクニック・テンポ配分で視聴者を惹きつけているのかを「再現可能なテンプレート」としてリバースエンジニアリングしてください。

# 分析対象データ
[対象のYouTube台本テキストや文字起こしデータをここに貼り付け]

# 出力フォーマット
以下の構成に従って、マークダウン形式で分かりやすく出力してください。

1. 【全体概要とバズの核心】
   - この動画が成功した最大の心理的要因（1文で）
   - 想定ターゲット層と彼らが抱えていた顕在・潜在ニーズ

2. 【タイムライン別・構成分解（セクション分析）】
   - 00:00 - 00:XX （フック層）：使用された心理トリガー、視聴者の離脱を防いだ仕掛け
   - 00:XX - 00:XX （問題・共感層）：感情を揺さぶるストーリーテリングの手法
   - 00:XX - 00:XX （本編・価値提供層）：情報の出し方の順序、飽きさせないテンポ変更の工夫
   - 00:XX - 00:XX （結び・CTA層）：行動を促したクロージングのフレーズ

3. 【抽出されたリユーザブル・テンプレート】
   - 他のテーマや商材でも流用できる「黄金の台本骨組み（穴埋め式）」を提示してください。

4. 【自社企画への応用アドバイス】
   - この構成を自社の[自社の商材やテーマをここに入力]に応用する場合の具体的な切り口案を3つ提案してください。
```

## 運用時の極意とハルシネーション（嘘の出力）を防ぐコツ

このプロンプトをさらに実務で爆速化させるためのテクニックをいくつか共有します。

1. <strong>文字起こしのノイズを事前に削る</strong>
   YouTubeの自動文字起こし機能を使うと、「えー」「あのー」といったフィラーや、無関係なBGMの誤認識が含まれます。これをそのまま放り込むとAIの精度が落ちるため、最低限のクリーニングをしてからプロンプトに渡すのがプロの技です。
2. <strong>Claude 3.5 Sonnetのアーティファクトを活用する</strong>
   長大な分析結果が出力される場合、Claudeのアーティファクト機能を使うと、独立したウィンドウで綺麗なマークダウンとして表示され、そのままNotionやGoogleドキュメントにエクスポートできます。企画書のトランスファーが圧倒的に楽になります。
3. <strong>温度（Temperature）の調整</strong>
   API経由やカスタムGPTで利用する場合は、創造性を少し抑えめ（0.2〜0.5程度）に設定すると、論理的でブレのない構造分析が得られます。

## よくある質問（FAQ）


Q1. 文字起こしデータがない長尺動画の場合はどうすればいいですか？
<strong>A:</strong> 動画の概要欄やチャプター情報、または主要なトピックの箇条書きを代わりにインプットし、「この公開情報とタイトルから、この動画がどのような台本構成であったかを逆推定して」と指示することで、ある程度の精度でリバースエンジニアリングが可能です。


Q2. 著作権やコンプライアンス上の問題はありませんか？
<strong>A:</strong> 競合の「構成の型（フレームワーク）」や「心理的アプローチのパターン」を分析することは、マーケティングや企画の領域では一般的な競合調査（ベンチマーク分析）の範囲内です。ただし、台本のテキストそのものをそのままコピーして自社チャンネルで公開することは避けてください。あくまで「構造のテンプレート」を抽出し、自社のオリジナルな言葉や一次情報に置き換えて企画書に昇華させるために使います。


Q3. ChatGPTとClaude、どちらのAIを使うのがおすすめですか？
<strong>A:</strong> どちらも非常に優秀ですが、長文の文脈理解力と、構造化された美しいアウトプット（アーティファクト機能）の面では、<strong>Claude 3.5 Sonnet</strong>に軍配が上がることが多いです。一方で、API連携やカスタムGPTとしての汎用性を重視する場合は<strong>ChatGPT（GPT-4o）</strong>が便利です。用途に合わせて使い分けてみてください。
